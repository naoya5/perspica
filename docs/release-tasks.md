詳しい条件は[公開前のライセンス確認](release-licenses.md)、

## 各タスクで残すもの

### S02：ソースとリソースの権利・表示

元の`LICENSE`のMITの許諾・著作権表示と、第三者の規約全文・出所記録は維持します。

以前のPDFワーカーとそのテスト（Attention論文由来の英文を含んでいた）は、2026-11-14に削除しました。
今のPDFのテストは公開論文`fixtures/attention.pdf`を使いますが、このファイルはリポジトリに含めません。
外部の文書をテストに使う場合は、ソース自体の許諾と区別し、本文やPDFを無断で再配布しません。

PDFの処理は、他のPDFライブラリのソースを読まず移植もしない方針で書きました（クリーンルーム）。
実装に関わったコーディングエージェントにも、この規則を指示しています。

[アイコン生成用ソース](../design/app-icon/make-candidates.swift)には、
SIL OFLの入力フォント6種が記されています。
現在の公開候補はSVGの図形で、フォント本体を配布する構成とは区別します。
[OFLの公式FAQ](https://openfontlicense.org/ofl-faq/)の1.1〜1.1.2では、
OFLフォントによるロゴ等の作成を認め、生成した図形へOFLを引き継ぐ必要はないと説明しています。
入力フォント6種の提供元とOFLの確認先は[第三者の通知](../THIRD_PARTY_NOTICES.md#icon-artwork)に記録しました。
制作時のフォントファイルの版・ハッシュを復元した記録ではありません。
将来フォント本体を含める場合は、その実物の条件を別途確認します。

### S04：公開する内容とGit履歴

2026-11-15に、現行候補301件と、作業開始時のHEADから到達する54コミット・617件の
ファイル内容の過去版を検査しました。秘密鍵、既知形式のトークン、認証情報らしい文字列、
個人の絶対パス、モデル・フォント本体やデータベース等のファイル名を対象とする一次検査です。
別ブランチ、reflog、到達不能なオブジェクトは対象外です。
任意の秘密情報や個人情報が存在しないことを保証する検査ではありません。

現行候補では、これらのパターンによる検出はありませんでした。
履歴には開発メモ・旧実装・検証記録の11ファイルに、個人の絶対パスが延べ17件ありました。
同じパスが異なる過去版に現れる分も含めた件数です。
この検査で認証情報のパターンは検出されていません。

配布者へ、パスからユーザー名やフォルダ構成は分かるものの、
それだけでMacやファイルへのアクセス権を得られるものではないと説明しました。
配布者は、最新版の公開対象やドキュメントに残っていなければ、
この17件を理由とする履歴の作り直しは不要と判断しました。履歴はそのまま残します。
この判断は公開操作の承認とは区別し、S06で改めて確認します。
