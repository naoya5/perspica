# 手で確かめる確認表

- 作った日: 2026-11-07（M4 のあと、M5 の前）
- 対象: `~/Applications/Yaku.app`（M4 まで入った版）
- 目的: キーを押す・選ぶ・ドラッグするなど、人の操作が要るので子スレッドも親も確かめられなかったこと。M1〜M4 の記録の「未確認」をここに集めた
- 書き方: 「結果」に ○ / × を入れ、× のときは「メモ」に何が起きたかを書く。全部やらなくてよい。**A と B だけでも M5 に進める**

## 0. 準備

1. Yaku を起動する（`open ~/Applications/Yaku.app`）。メニューバーにアイコンが出る
2. **アクセシビリティの許可**: システム設定 → プライバシーとセキュリティ → アクセシビリティ → `+` で `~/Applications/Yaku.app` を足してオンにする（⌃⌥J と置き換えに要る）
3. **画面収録の許可**は、C で初めて ⌃⌥O を押したときに macOS が聞いてくる。そこで許可する（許可のあと Yaku の再起動を求められたら従う）
4. 通知は、初めて PDF が終わったときに聞いてくる。許可する
5. **B の前に**: 設定 → PDF の「導入する」で PDF ワーカーを入れる（約 950MB、1 分ほど）。いまは「未導入」
6. ⌃⌥J・⌃⌥K・⌃⌥O がほかのアプリ（SkillHub など）のショートカットと重なっていると、Yaku に届かない。効かないときは、設定 → ショートカットで別のキーにする

注意:
- Yaku は 1 つしか起動できない。親が撮影するときは Yaku を終了してもらう
- アプリを作り直すと、許可が外れることがある。急に ⌃⌥J が「許可が必要です」に戻ったら、2 をやり直す
