# Yaku M4（画面翻訳）を作る

あなたはローカル翻訳アプリ「Yaku」（仮称）の段階 M4 を実装する。M0〜M3 は別のスレッドが作り、親（私）がレビュー済み。設計・レビューは親が持つ。

## 最初に（画面のロックが解けているときだけ）
M2・M3 の撮影と計測がまだ。`ioreg -n Root -d1 -a | plutil -extract IOConsoleUsers xml1 -o - - | grep -A1 CGSSessionScreenIsLocked` で何も出なければ解けている。解けていたら、**M4 のコードに手を入れる前に** `app/` で `swiftc -O tools/winid.swift -o /tmp/winid` → `tools/capture-m2.sh` → `tools/capture-m3.sh` → `tools/measure-m2.sh` → `tools/measure-m3.sh` を走らせ、結果を `docs/checks/M2.md`・`M3.md` の撮影と計測の欄に書き足す（画像は自分で開いて見て、気づいたことも書く）。作業の途中で解けたら、そのときにやる（M4 のコードを含む状態だと書く）。撮影中はほかの Yaku を起動しない

## M4 で作るもの
1. ⌃⌥O（設定で変えられる。M2 のショートカットの仕組みを使う）とパネルの「画面を翻訳」ボタン
2. 範囲の選び方（SPEC 4.6 の 1）: 暗幕・ガラスのカプセル `ウィンドウ｜範囲｜画面全体`・カーソルの下の窓の枠・ドラッグ・Space・Esc。マウスのある画面で出す
3. 撮影（SPEC 9）: ScreenCaptureKit の `SCScreenshotManager`、自分の窓は除く、Retina のまま。画面収録の許可がないときは SPEC 13 章の文言と「システム設定を開く」（使う直前に 1 回だけ聞く。何度も聞き直さない）
4. 読み取りとまとめ方（SPEC 9）: Vision の `RecognizeTextRequest`。ブロックにまとめる規則・ハイフンの連結・確からしさ 0.3 未満を捨てる。**まとめ方は YakuCore に置き、行の配置の見本でテストする**
5. 訳（SPEC 5.2 の F4 の文脈、最大 3 件を同時、上から順に、優先度は対話より下・PDF より上）。用語集とキャッシュは M1・M2 の仕組みのまま
6. 重ね表示（SPEC 4.6 の 3〜5）: 背景色で塗った下地・元の文字色・大きさの合わせ方（70% まで）・はみ出し・160ms のフェード、下の帯（原文を表示（⌥）・すべてコピー・閉じる（Esc））、ブロックのクリックでコピー、スクロール・窓の移動・アプリの切り替えで 200ms で消える。訳文がないときの文言（SPEC 13 章）
7. 起動オプション: `--demo-image <png> [--demo-scale <倍率>]`（撮影の代わりにその画像を読み取り、画面に重ねる。画像は画面の左上から置く）、`--demo-surface overlay-picker`（範囲の選び方の画面）、`--demo-quit-after`
8. 設定の画面翻訳タブを本物にする（読み取る言語・最小の文字の大きさ）

## 確かめること
1. `swift build`・`swift test` が警告なしで通る（まとめ方・ハイフン・文字の大きさの合わせ方・背景色の取り方にテスト）
2. `./make-app.sh install`（Authority=Yaku Signing）
3. 見本の画像を 3 つ用意する（自分の一時のフォルダで作る。例: HTML を Safari ではなく `WKWebView` の小さな Swift スクリプトや `qlmanage`、Python などで PNG にする。英語の記事 1 画面・2 段組・UI の画面）。`--demo-image` と、読み取りだけを確かめる経路（YakuCore のテスト、または `--demo-image ... --demo-dump-blocks` で JSON を出す）で、ブロックの数・まとまり方・訳を表にする。**読み取りから全部重なるまでの時間**（目標: 最初のブロック 1 秒、全部 3 秒）
4. 画面のロックが解けていれば: 重ね表示と範囲の選び方の撮影（ライトとダーク）を `docs/checks/shots/M4-*.png`、自分で開いて見る（下地が元の文を隠しているか、文字の大きさ、帯のガラス）。CPU（重ね表示を出している間）。本物の画面の撮影は、Yaku に画面収録の許可がないので許可がないときの表示を確かめる。許可を勝手に与えない
5. 人の操作が要るもの（⌃⌥O・範囲を選ぶ操作・クリック・⌥・スクロールで消える・許可を与えたあとの本物の撮影）は「未確認」と書く。マウスやキーを送るツール、ほかのアプリを動かすことは使わない

## 守ること
- 書いてよいのは `projects/translate-app/app/`・`projects/translate-app/docs/checks/` の中、`~/Applications/Yaku.app`、`~/Library/Application Support/Yaku/`、`~/Library/Logs/Yaku/`、`$TMPDIR` の下の一時のフォルダだけ。SPEC.md・context.md・lab/・pdf-worker/・リポジトリのほかの場所は変えない（仕様のおかしいところは M4.md に書く）

- git の commit・push はしない。有料の API・ネットワークは使わない

- ほかの llama-server（5191・5192 など）に触らない。システムの設定（画面収録の許可など）を変えない
