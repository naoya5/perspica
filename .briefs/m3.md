## M3 で作るもの
1. **PDF ワーカー**（SPEC 8.2）: `projects/translate-app/pdf-worker/`
   - `translate_pdf.py`（試作の engine/translate_pdf.py が元）と、pdf2zh-next の `--clitranslator` から呼ばれる段落の翻訳プログラム。段落の翻訳は SPEC 7.2 と同じ PFML3（文脈 = 文書の題名、用語集、文体）を作り、アプリが起動したエンジンに `--engine-url` と `--api-key` で送る（API キーはコマンド行ではなく環境変数で子に渡す）。`requirements.txt`（`pdf2zh-next==2.9.0`、`bitstring<5`）
   - 導入: 初めて PDF を受け取ったら SPEC 13 章の文言で聞き、`uv`（`/opt/homebrew/bin/uv`、0.13.5 がある）で Python 3.12 の環境を `~/Library/Application Support/Yaku/pdf-worker/` に作る。進み具合を出す。導入後の大きさを測って文言の「約 ___MB」に入れる。開発用に、設定（または起動オプション `--pdf-python <path>`）で `lab/plamo-pdf-translate/.venv/bin/python` を使えるようにする
   - 進み具合の JSON 行・段階の日本語名・取り消し（SIGTERM → 3 秒 → SIGKILL）は SPEC 8.2
   - PDF の処理中はエンジンを止めない（使わない時間の数え方から外す）。ワーカーの同時の依頼は 3 まで（対話用に 1 枠空ける）
2. **受け付けと順番待ち**（SPEC 8.1）: 1 件ずつ。暗号化された PDF と PDF 以外を断る。`PDFJob`（SPEC 11 章）に記録
3. **出力**（SPEC 8.3）: 名前のつけ直し（`<元>.ja.pdf` と `<元>.ja.対訳.pdf`、重なれば ` (2)`）、書けなければ `~/Downloads`、完了したら開く（設定に従う）、パネルが閉じていれば通知（`UNUserNotificationCenter`、「開く」の操作つき）
4. **入口 5 つ**: メニューバーのアイコン（ドラッグが来たらパネルをドロップの状態で開く）、パネル（ドロップの状態。SPEC 4.2 の表。PDF 以外は揺れる）、管理画面の PDF のページ（SPEC 4.4。サムネイルは QuickLookThumbnailing）、島、Finder の「このアプリで開く」（`CFBundleDocumentTypes`）とパネルの「PDF を開く…」（⌘O）
5. **表示**: パネルの作業中の PDF の行（SPEC 4.2 の 6）、メニューバーのアイコンの進み具合と完了・失敗（SPEC 4.1）、島（SPEC 4.5。closed / drop / activity / done / error。試作の見た目を移し、上の耳が小さな黒い突起に見える問題を実画面で合わせ直す。設定「ノッチを使う」に従う。ノッチのない画面では出さない）
6. **設定の PDF タブ**（SPEC 4.4）を本物にする
7. **起動オプション**: `--demo-pdf <path> [--pdf-pages <範囲>]`（ドロップと同じ経路）、`--demo-surface notch --demo-state drop|activity|done|error`、`--demo-surface panel --demo-state drop|pdf-running|pdf-done`、`--pdf-python <path>`
8. 8B のモデルのカードに「16GB の Mac ではほかのアプリを閉じて使う」を足す（SPEC 7.5 の表を直した）

## 守ること
- 書いてよいのは `projects/translate-app/app/`・`projects/translate-app/pdf-worker/`・`projects/translate-app/docs/checks/` の中、`~/Applications/Yaku.app`、`~/Library/Application Support/Yaku/`、`~/Library/Logs/Yaku/`、`$TMPDIR` の下の一時のフォルダだけ。SPEC.md・context.md・lab/・リポジトリのほかの場所は変えない（lab/ の PDF と .venv は読む・使うだけ）
- 署名は `make-app.sh` のとおり。パスワードのファイルの中身をどこにも書かない
- git の commit・push はしない。有料の API は使わない。ネットワークは PyPI と Python の取得（uv が使うもの）と Hugging Face だけ
- `rm -rf` やワイルドカードでの削除はしない（`make-app.sh` の中の具体的なパスと、上の一時のフォルダは除く）
- 自分が起動したプロセス以外を止めない。`pkill -f` / `killall` は使わない。終わる前に、自分が起動した llama-server・Yaku・PDF ワーカーが残っていないことを確かめる
- ほかの llama-server（5191・5192 など）に触らない。システムの設定（通知の許可など）を勝手に変えない
- `curl` は hook で止められることがある。HTTP は `python3 -c "import urllib.request; ..."` か、アプリの `URLSession` で
