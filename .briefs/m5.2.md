# M5.2 — 短いラベルの訳を縮めず横に伸ばす・大きさの違う 2 行を分ける

M5.1 は受け取った（親のレビューは `docs/checks/M5.md` の 8.7）。残った 2 つを直す。

## 1. 1 行だけのブロックは、縮める前に横へ伸ばす（SPEC 4.6 の 3 を変える）

いまは「元の枠に収まらなければ 70% まで縮め、それでも入らなければ下へはみ出す」。短いラベル（1 行のブロック）でこれをやると「プライバシ／ー」「アプリごとにグルー／プ化」のように縮んで単語の途中で折れる。

新しい順番（1 行のブロックだけ。2 行以上の段落は今までどおり）:

1. 元の大きさのまま、**右へ伸ばして 1 行に収まるか**を見る。伸ばしてよいのは、同じ高さの範囲にある次のブロックの左端の手前まで（すきま 8pt 程度を残す）、それが無ければ撮影した範囲の右端の手前まで
2. 伸ばしても入らなければ、伸ばした幅の中で 70% まで縮める
3. それでも入らなければ、今までどおり下へはみ出す
- 折り返すときは、長音・小さい仮名・句読点を行の頭に置かない（禁則）。SwiftUI の `Text` がこの幅でそうしない場合は、まず縮めるほうを優先するなどで避ける
- 伸ばした分の下地（元の文を隠す塗り）も同じ幅にする
- `SPEC.md` 4.6 の 3 を新しい順番に書き換える

## 2. 大きさが違う 2 行を分ける

`Show in Lock Screen` / `Keep recent items visible` は、幅の比が 1.01 なので行の長さでは分けられない。墨の帯から出した大きさは 11.5% 違う（段落の中は 1.6〜2.1%）。M5.1 の 8.5 に書いた「大きさが 8% 以上違う行は別のまとまり」を入れる。

- 和文の段落に欧文の行が混ざると大きさが開くかもしれない、という心配は、**測って確かめる**: 記事・2 段組・UI の 3 見本に加えて、和文と欧文の混ざった段落の見本を 1 つ作り（`tools/make-samples.swift` に足す）、段落が切れないことを示す。切れるなら、境目の値を変えるか、比べ方を「x の高さ」などに変えて、理由を書く
- ブロックの数: 記事 5、2 段組 5 のまま。UI は 13 → 14 になるはず
